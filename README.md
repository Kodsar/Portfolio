# Portfolio Website 

A modern, responsive personal portfolio website showcasing backend development skills, experience, and projects.

## 🚀 Features

- **Responsive Design** - Compatible with all devices (mobile, tablet, desktop)
- **Smart Navigation** - Hamburger menu for mobile and regular menu for desktop
- **Modern Structure** - Clean and professional design with balanced color scheme
- **Complete Sections** - Includes About, Experience, Projects, and Contact sections
- **Interactivity** - Clickable buttons and smooth animations

## 📱 Responsiveness

The website is optimized for 3 different states:

1. **Desktop**: Width greater than 1200px
2. **Tablet**: Width between 768px and 1200px
3. **Mobile**: Width less than 768px
